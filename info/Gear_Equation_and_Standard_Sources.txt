IMPORTANT SCOPE NOTES
- VDI 2736 Blatt 2 Method C is the intended calculation method. Do not replace with Method B equations.
- Equal sharing means total mesh force divided by 3 for per-planet tooth stress. Aggregate each planet-path loss x 3 for system heat only; check that input is per-path before aggregation.
- Generic root geometry in vdi2736.m (s_Fn=pi*m_n/2, h_Fa=1.25m_n, rho_F=0.38m_n) is not an actual profile calculation and omits the proposed positive profile shifts.
- The internal ring's YSa is explicitly an approximation; VDI 2737 equations have not been implemented.
- No applicable SLS PA12 gear S-N curve is incorporated. The paper with DOI 10.1177/14644207221074902 is pending user-provided copy/data and is not yet a source for calculated life.
- User-reported 30.4 MPa root stress, 40.4 MPa flank pressure, and ~49 deg C are not validated by these source notes; verify against an executed current model/configuration before quoting as reproduced results.

PA12 FATIGUE PDF CURRENTLY USED FOR A LIMITED ROOT SCREEN
TA Instruments EF037, “Tensile and Fatigue Properties of Additively Manufactured Polyamides.” PDF filename: EF037.pdf. Direct PDF: https://www.tainstruments.com/pdf/literature/EF037.pdf. Source page: https://www.tainstruments.com/applications-notes/tensile-and-fatigue-properties-of-additively-manufactured-polyamides/.
The note tests SLS PA12 dog-bone coupons at 25 Hz and R=0.1. The reported PA12 25 MPa specimens ran out at 10^7 cycles; failures used to fit the trendline span 30–40 MPa. Current modeled root stress is below the tested range, so code records >=10^7 cycles as a provisional monotonic/runout-based lower-bound projection only. It does not claim exact cycles to failure. The gear temperature is much higher than the coupon test condition and no correction is available. This S-N data does not assess flank contact fatigue.
