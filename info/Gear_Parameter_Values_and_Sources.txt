FATIGUE SCREEN NOW USED IN CODE
- TA Instruments EF037, “Tensile and Fatigue Properties of Additively Manufactured Polyamides”; PDF filename: EF037.pdf; source page: https://www.tainstruments.com/applications-notes/tensile-and-fatigue-properties-of-additively-manufactured-polyamides/; direct PDF: https://www.tainstruments.com/pdf/literature/EF037.pdf.
- Source test: SLS PA12 tensile dog-bone coupons, R=0.1, 25 Hz. All PA12 samples at 25 MPa ran out at 10^7 cycles; failures occurred at 30–40 MPa. Model applies the 25 MPa/10^7 runout as a projected lower bound for root-bending stresses below 25 MPa. It is not an exact fatigue failure life.
- Current modeled root stresses (about 3–5.4 MPa in the supplied run) are far below tested failure stresses. Current open-case gear temperature (about 88.7 C) is above the coupon test condition; no temperature factor is applied. Treat this only as an optimistic screening placeholder until matched-temperature gear tests exist.
- Tensile S-N data do not represent flank contact fatigue. That mode remains unassessed; VDI average wear remains the flank life estimate.
